# Inner Home PR-2

Главная `inner` теперь управляется через существующие `ContentBlock` без новой CMS-модели.

## Что управляется

- `hero.*`
  - заголовок, подзаголовок, описание
  - CTA текст и ссылка
  - изображение и `alt`
  - отдельные флаги видимости для hero, бейджа, подзаголовка, описания, CTA и изображения
- `home.directions.*`
  - заголовок и подзаголовок секции
  - CTA секции
  - три карточки направлений
  - у каждой карточки: `title`, `description`, `categorySlug`, `href`, `image.src`, `image.alt`, `sortOrder`, `isVisible`
- `home.sections.order`
  - CSV-порядок секций: `directions,newArrivals,howToOrder,news,articles,reviews`

## Как работают fallback

- Для направлений категория выбирается по `categorySlug`.
- Если у карточки не задан `href`, используется `/catalog/{slug}`.
- Если не задано изображение, берётся `Category.image`, затем локальный fallback из `catalog-categories`.
- Если не задан заголовок, используется `Category.title`.
- Если не задано описание, используется `Category.catalogTeaser`, если он есть.
- Скрытые карточки и пустые карточки не рендерятся.

## Ограничения

- Изменения касаются только витрины `inner`.
- Ветка `sprint-power` продолжает использовать существующую структуру главной.
- Переупорядочивание секций сделано без новой сущности: порядок хранится в `ContentBlock` строкой CSV.
